# Glossary
Described below are any terms that may be important to the development or understanding of this ECS.
## Acronyms
### ECS
Entity Component System - a general term used to describe the kind of project supported by the Archive.
## Definitions
### App
A container for all entities, components, and systems within an instance of a project.
### Entity
A unique object within an App. Contains components.
### Component
Data that is attached to an entity and used in systems.
### Prototype
A serialized definition of a data structure written in YAML and loaded by the App to instantiate an entity or data type.
### Module
A package that extands an App with runtime capabilities
### Project
Any application built on the Archive
